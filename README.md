# UCI IEEE Open Project Space

Projects and work from my participation in **IEEE at UCI's Open Project Space (OPS)** during the 2026–2027 academic year.

OPS is a year-long, student-led embedded systems course: eight guided projects covering circuits, soldering, microcontrollers, embedded C++, communication protocols, and PCB design, followed by a capstone where each student designs and builds a remote-controlled rover.

Projects follow the schematics and specs published on the [OPS program site](https://ieee.ics.uci.edu/ops-program/). Each write-up notes what was provided and what I did myself.
